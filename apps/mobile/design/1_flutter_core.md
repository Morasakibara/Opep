# OPEP Mobile — Architectural Foundation (Flutter)

This document outlines the core architectural patterns, folder structure, and foundational code stubs for the OPEP mobile application. The architecture is designed using **Clean Architecture** principles and incorporates state-of-the-art Flutter development patterns to ensure scalability, testability, and responsiveness.

### Architectural Layer Responsibilities
1. **Domain Layer (Core Business Logic)**
   * **Entities**: Plain Dart objects representing the domain data (e.g., `User`, `Ticket`, `Trip`, `Complaint`).
   * **Repositories (Interfaces)**: Contract definitions for repositories. Ensures domain logic remains decoupled from specific databases or API packages.
   * **Use Cases**: Encapsulates specific business rules (e.g., `PostponeReservation`, `ValidateTicketOffline`, `SubmitComplaint`).
2. **Data Layer (Infrastructure)**
   * **Models**: Dart classes representing raw API JSON or SQL rows, including serialization/deserialization logic (`fromJson`, `toJson`). Extends Domain Entities.
   * **Repositories (Implementations)**: Concrete implementation of domain contracts. Orchestrates data fetching from Remote and Local DataSources.
   * **Data Sources**: Interacts directly with external frameworks (Dio for REST APIs, SQLCipher for SQLite, FlutterSecureStorage for credentials).
3. **Presentation Layer (UI & State)**
   * **BLoCs/Cubits**: State managers responding to user events, invoking use cases, and yielding states.
   * **Pages**: UI views.
   * **Widgets**: Reusable visual components.

## 3. Navigation & Routing (go_router)

`go_router` handles client navigation, checking authentication status and performing role-based routing (passenger Client, Driver, Controller).

### `lib/core/router/app_router.dart`
```dart
import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class AppRouter {
  final FlutterSecureStorage _secureStorage;

  AppRouter(this._secureStorage);

  late final GoRouter router = GoRouter(
    initialLocation: '/splash',
    debugLogDiagnostics: true,
    redirect: (BuildContext context, GoRouterState state) async {
      final accessToken = await _secureStorage.read(key: 'access_token');
      final userRole = await _secureStorage.read(key: 'user_role'); // CLIENT, DRIVER, CONTROLLER
      
      final isLoggingIn = state.matchedLocation == '/login' || state.matchedLocation == '/register';
      final isSplash = state.matchedLocation == '/splash';

      // 1. Unauthenticated User
      if (accessToken == null) {
        if (isSplash) {
          return '/login';
        }
        return isLoggingIn ? null : '/login';
      }

      // 2. Authenticated User trying to access auth pages
      if (isLoggingIn || isSplash) {
        if (userRole == 'DRIVER') {
          return '/driver/dashboard';
        } else if (userRole == 'CONTROLLER') {
          return '/controller/dashboard';
        } else {
          return '/home';
        }
      }

      // 3. Role-Based Navigation Guards
      final targetPath = state.matchedLocation;
      if (targetPath.startsWith('/driver') && userRole != 'DRIVER') {
        return '/home'; // Redirect passenger/controller to passenger home
      }
      if (targetPath.startsWith('/controller') && userRole != 'CONTROLLER') {
        return '/home';
      }
      if (targetPath.startsWith('/home') && (userRole == 'DRIVER' || userRole == 'CONTROLLER')) {
        return userRole == 'DRIVER' ? '/driver/dashboard' : '/controller/dashboard';
      }

      return null; // Proceed to target route
    },
    routes: [
      GoRoute(
        path: '/splash',
        builder: (context, state) => const SplashScreen(),
      ),
      GoRoute(
        path: '/login',
        builder: (context, state) => const LoginPage(),
      ),
      GoRoute(
        path: '/register',
        builder: (context, state) => const RegisterPage(),
      ),
      
      // Passenger Client Main Navigation Stack
      GoRoute(
        path: '/home',
        builder: (context, state) => const HomePage(),
        routes: [
          GoRoute(
            path: 'trips/:tripId',
            builder: (context, state) {
              final tripId = state.pathParameters['tripId']!;
              return TripDetailPage(tripId: tripId);
            },
          ),
          GoRoute(
            path: 'booking',
            builder: (context, state) => const BookingPage(),
          ),
          GoRoute(
            path: 'payment',
            builder: (context, state) => const PaymentPage(),
          ),
          GoRoute(
            path: 'tickets/:ticketId',
            builder: (context, state) {
              final ticketId = state.pathParameters['ticketId']!;
              return TicketDetailPage(ticketId: ticketId);
            },
          ),
          GoRoute(
            path: 'tracking/:tripId',
            builder: (context, state) {
              final tripId = state.pathParameters['tripId']!;
              return TrackingPage(tripId: tripId);
            },
          ),
          GoRoute(
            path: 'review/:tripId',
            builder: (context, state) {
              final tripId = state.pathParameters['tripId']!;
              return ReviewPage(tripId: tripId);
            },
          ),
          GoRoute(
            path: 'complaint',
            builder: (context, state) => const ComplaintPage(),
          ),
        ],
      ),

      // Driver Interface Stack
      GoRoute(
        path: '/driver/dashboard',
        builder: (context, state) => const DriverDashboardPage(),
      ),

      // Controller Interface Stack
      GoRoute(
        path: '/controller/dashboard',
        builder: (context, state) => const ControllerDashboardPage(),
      ),
    ],
  );
}
```

## 4. Dio HTTP Client & JWT Interceptor

To manage secure communication, the `DioClient` initiates requests and handles token expiration using Dio's `QueuedInterceptor`. This interceptor queues outgoing API requests when an `accessToken` expires, requests a token renewal via the refresh endpoint, updates the local storage, and then retries the queued requests seamlessly.

### `lib/core/network/jwt_interceptor.dart`
```dart
import 'package:dio/dio.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class JwtInterceptor extends QueuedInterceptor {
  final FlutterSecureStorage _secureStorage;
  final Dio _refreshDio; // Distinct Dio instance for refreshing to avoid infinite loops

  JwtInterceptor(this._secureStorage, this._refreshDio);

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) async {
    final accessToken = await _secureStorage.read(key: 'access_token');
    if (accessToken != null) {
      options.headers['Authorization'] = 'Bearer $accessToken';
    }
    super.onRequest(options, handler);
  }

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) async {
    // Intercept 401 Unauthorized errors and verify we are not already trying to login/refresh
    if (err.response?.statusCode == 401 &&
        err.requestOptions.path != '/auth/login' &&
        err.requestOptions.path != '/auth/refresh') {
      
      final refreshToken = await _secureStorage.read(key: 'refresh_token');
      if (refreshToken == null) {
        return super.onError(err, handler); // No refresh token available, fail request
      }

      try {
        // Run refresh request sequentially
        final response = await _refreshDio.post(
          '/auth/refresh',
          data: {'refreshToken': refreshToken},
        );

        if (response.statusCode == 200 || response.statusCode == 201) {
          final data = response.data;
          final newAccessToken = data['accessToken'];
          final newRefreshToken = data['refreshToken'];

          // Save new tokens
          await _secureStorage.write(key: 'access_token', value: newAccessToken);
          await _secureStorage.write(key: 'refresh_token', value: newRefreshToken);

          // Clone the request with the updated token header and retry
          final options = err.requestOptions;
          options.headers['Authorization'] = 'Bearer $newAccessToken';

          final clonedRequest = await _refreshDio.fetch(options);
          return handler.resolve(clonedRequest);
        }
      } catch (refreshErr) {
        // Refresh token is expired or invalid. Clear user credentials and force re-auth.
        await _secureStorage.delete(key: 'access_token');
        await _secureStorage.delete(key: 'refresh_token');
        await _secureStorage.delete(key: 'user_role');
        
        // Return standard error to trigger redirect logic in presentation layer
        return super.onError(err, handler);
      }
    }
    super.onError(err, handler);
  }
}
```

### `lib/core/network/dio_client.dart`
```dart
import 'package:dio/dio.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';
import 'jwt_interceptor.dart';

class DioClient {
  final Dio dio;
  final FlutterSecureStorage _secureStorage;

  DioClient(this.dio, this._secureStorage) {
    dio.options
      ..baseUrl = 'https://api.opep.cm/api/v1' // Update with target server URL
      ..connectTimeout = const Duration(seconds: 15)
      ..receiveTimeout = const Duration(seconds: 15)
      ..headers = {
        'Content-Type': 'application/json',
        'Accept': 'application/json',
      };

    // Separate clean Dio instance for token renewal to prevent recursion and interceptor loops
    final refreshDio = Dio(
      BaseOptions(
        baseUrl: dio.options.baseUrl,
        connectTimeout: const Duration(seconds: 10),
        receiveTimeout: const Duration(seconds: 10),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
      ),
    );

    dio.interceptors.addAll([
      JwtInterceptor(_secureStorage, refreshDio),
      LogInterceptor(
        requestBody: true,
        responseBody: true,
        error: true,
      ),
    ]);
  }
}
```

```dart
// Custom theme extension to handle ticket cards, custom badges, or gradient elevations
class OpepThemeExtension extends ThemeExtension<OpepThemeExtension> {
  final Gradient primaryGradient;
  final Color ticketBackground;
  final Color statusPending;

  OpepThemeExtension({
    required this.primaryGradient,
    required this.ticketBackground,
    required this.statusPending,
  });

  @override
  ThemeExtension<OpepThemeExtension> copyWith({
    Gradient? primaryGradient,
    Color? ticketBackground,
    Color? statusPending,
  }) {
    return OpepThemeExtension(
      primaryGradient: primaryGradient ?? this.primaryGradient,
      ticketBackground: ticketBackground ?? this.ticketBackground,
      statusPending: statusPending ?? this.statusPending,
    );
  }

  @override
  ThemeExtension<OpepThemeExtension> lerp(
    ThemeExtension<OpepThemeExtension>? other,
    double t,
  ) {
    if (other is! OpepThemeExtension) {
      return this;
    }
    return OpepThemeExtension(
      primaryGradient: Gradient.lerp(primaryGradient, other.primaryGradient, t)!,
      ticketBackground: Color.lerp(ticketBackground, other.ticketBackground, t)!,
      statusPending: Color.lerp(statusPending, other.statusPending, t)!,
    );
  }

  // Light Mode Defaults
  static final light = OpepThemeExtension(
    primaryGradient: const LinearGradient(
      colors: [Color(0xFF008751), Color(0xFF00A865)],
      begin: Alignment.topLeft,
      end: Alignment.bottomRight,
```
